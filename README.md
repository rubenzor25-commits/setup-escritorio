# Setup de escritorio

Opciones con precio y enlace para montar el setup de Rubén: mesa elevable, dos pantallas bajo el MSI MAG 401QR de 40", brazos 2+1, Mac mini o Mac Studio y sillas giratorias para el salón. Incluye un configurador que suma el presupuesto.

Publicada en https://rubenzor25-commits.github.io/setup-escritorio/

Los datos salen de `../investigacion/` (un JSON por categoría + `extra.json` con textos y recomendaciones):

```bash
cd ../investigacion && python3 -I construir.py
cd ../web && npm run build && npm run deploy
```

Precios consultados el 18/10/2026; pueden cambiar.
